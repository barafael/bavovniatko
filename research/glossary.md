# Glossary

Compiled from the Terms sections of the topic files. The last column shows which topic files use each
term (00–08; see [README](README.md)). Ukrainian terms are transliterated, with Cyrillic where the
source gave it. Terms marked *(RU)* are Russian and appear as Ukrainian and Western sources report them.
Terms marked *(unverified)* are common usage that no source in this pack confirms.

## Frontline and soldier slang (Ukrainian)

| term | meaning | topics |
|---|---|---|
| **bavovna** (бавовна) | "Cotton". Ironic slang for explosions on Russian-held targets. It mocks the Russian euphemism *khlopok* (хлопок), which means both "pop/bang" and "cotton". The game's name, *bavovniatko*, comes from this word. | 00, 03 |
| **nul / nulovka / nulova liniia** (нуль, нульова лінія) | The "zero line", the forward-most occupied positions. *Na nuli* means "at the zero". | 04, 05 |
| **sira zona** (сіра зона) | Grey zone: the contested ground between the lines. By 2025–26 it is often used as a synonym for the kill zone. | 00, 01, 04, 05, 06 |
| **kilzona / zona urazhennia** (кілзона) | Kill zone: the drone-saturated belt where anything that moves gets struck. It is measured by strike density rather than the maximum range of a drone. About 10–15 km deep in 2025 and 15–30 km by 2026. | 00, 01, 02, 04, 05 |
| **LBZ** (liniia boiovoho zitknennia) | Line of contact. | 00 |
| **lisosmuha** (лісосмуга, pl. *lisosmuhy*) | Shelterbelt or treeline: a planted windbreak strip between fields. Russian *lesopolosa*. | 04, 06 |
| **posadka** (посадка, pl. *posadky*) | Soldiers' word for a treeline. | 05, 06 |
| **zelenka** | Foliage season, or green cover *(unverified)*. | 06 |
| **blindazh** (бліндаж) | Dugout or bunker with overhead cover. | 04, 05 |
| **pozytsiia** (позиція) | A position, the basic unit of Ukrainian defence, often held by 2–3 soldiers. | 04 |
| **pikhota** (піхота) | Infantry. Troops use it for the scarce trench infantry that everything depends on. | 04 |
| **shturmovyk / shturmovyky** (штурмовик) | Assault soldier(s). Also used for the new assault regiments and the Assault Forces. | 00, 04 |
| **rotatsiia** (ротація) | Rotation of troops on and off positions. | 04 |
| **evak** (евак) | Evacuation, usually casualty evacuation. | 04, 05 |
| **"200" / "300"** | Soviet-derived codes still in use: 200 = killed, 300 = wounded. | 04 |
| **arta** (арта) | Artillery. *Nasha arta* means "our guns". | 03 |
| **prylit / vylit** (приліт / виліт) | "Arrival" and "departure": an incoming impact, and an outgoing launch or sortie. | 03 |
| **tryvoha** (тривога) | Air-raid alert. | 03 |
| **ptashky / ptakhy / ptashka** (пташки / птахи) | "Little birds" / "birds": drones. The source of the unit name "Magyar's Birds". | 01, 05 |
| **mavik** (мавік) | Any small reconnaissance quadcopter, from the DJI Mavic. | 01, 05 |
| **skyd** (скид, pl. *skydy*) | A drop: a munition or supply bundle released from a drone. | 01, 04, 05 |
| **optovolokno / optyka** (оптоволокно) | Fibre-optic FPV drone, steered through an unspooling cable and immune to radio jamming. | 00, 01, 02, 05 |
| **moped / mopedy** (мопед) | Shahed/Geran drones, named for the moped-like sound of their engines. | 00, 01, 02, 03, 05 |
| **shakhedy** (шахеди) | Shaheds, used generically for Geran one-way attack drones. | 01, 03 |
| **Baba Yaga / Babka / Baba Yaha** | The folk witch. Russian soldiers' name for Ukrainian heavy night bomber drones, which Ukrainians adopted. | 01, 05 |
| **zhdun** (pl. *zhduny*) | "Waiter": an ambush drone that lands near a road and waits for a target. | 02 |
| **mangal** | "Barbecue grill": improvised cage armour against drones. | 02, 04 |
| **cherepakha** (черепаха) | "Turtle": a Russian vehicle fully boxed in against drones. | 02, 04 |
| **sitka / tunel** | Anti-drone netting, and a net tunnel over a road. | 02 |
| **okopnyi REB / kupol / ryukzak REB** | Trench jammer, a jammer's protective "dome", and a backpack jammer. | 02 |
| **REBivets** | EW operator. | 02 |
| **maket** (макет) | Decoy or mock-up, such as a fake HIMARS. | 05 |
| **SZCh** (СЗЧ) | Leaving a unit without authorisation, i.e. AWOL (Criminal Code Art. 407). Desertion is Art. 408. | 04 |
| **TTsK** (ТЦК) / **busyfikatsiia** | The territorial recruitment centre (draft office), and slang for forcible street mobilisation into vans. | 04 |

## Wargaming and game terms

| term | meaning | topics |
|---|---|---|
| **Loitering munition** | A drone munition that searches before striking. | 08 |
| **Dropper / bomber** | A multirotor that drops munitions instead of diving in. | 08 |
| **RSSI / LQ** | Received signal strength and link quality: measures of drone-link health. | 08 |
| **ISR** | Intelligence, surveillance, reconnaissance. | 05, 08 |
| **OOB** | Order of battle. | 08 |
| **WeGo** | A simultaneous-turn system (as in Combat Mission): both sides plot, then execute together. | 08 |
| **CPX** | Command post exercise: staff training driven by a simulation. | 08 |
| **Matrix game** | An argument-based, adjudicated wargame, common in professional wargaming. | 08 |
| **Double-blind** | Neither side sees the other's forces except through reports. | 08 |
| **KShVI** | Russian command-staff military games. | 08 |
| **Goodhart's law** | When a measure becomes a target, it stops measuring what matters. Relevant to e-points. | 08 |
| **Lob / pitch-up fire** | A helicopter or jet climbs and releases unguided rockets on a ballistic arc, staying out of MANPADS range. | 03 |
| **FARP / IADS / CAP / stand-off** | Forward arming and refuelling point; integrated air defence system; combat air patrol; releasing a weapon from outside the enemy's air-defence envelope. | 03 |
